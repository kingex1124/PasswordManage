# Spec20250224 需求缺口 QA 問題集

> 使用方式：請直接在每題「你的答案」填寫。你填完後，我會依此更新詳細規格文件。

## A. 資料生命週期與匯入策略

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q1 | 匯入檔案時，若目前畫面已有資料，預設要「覆蓋全部」、「合併資料」還是「先提示使用者選擇」？ | 覆蓋全部 |
| Q2 | 若選擇合併，資料唯一鍵要用什麼判斷？（例：類別+種類+帳號，或使用內部 id） | 覆蓋全部，所以無此問題 |
| Q3 | 刪除一筆帳號資料時，是否需要二次確認？ | 是 |
| Q4 | 密碼歷程是否允許刪除舊歷程？若允許，是否保留刪除紀錄？ | 可以刪除歷程，不用保留刪除紀錄 |

## B. 密碼與安全政策

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q5 | 存檔密碼最小長度要幾碼？是否要求英數混合或特殊字元？ | 完全沒有限制，因為各平台情況不一樣 |
| Q6 | 要不要提供「存檔密碼強度提示」？（弱/中/強） | 不用 |
| Q7 | 連續解密失敗是否需要限制次數或延遲重試？ | 延遲5秒 |
| Q8 | 匯入後是否允許暫時記住存檔密碼於記憶體（直到關閉分頁）？ | 允許 |
| Q9 | 你是否接受使用 PBKDF2 iterations = 100000 作為預設？若否，請提供值。 | 可以 |

## C. 密碼歷程規則

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q10 | 新增密碼歷程的日期是否可手動修改？或永遠用系統當下時間？ | 可以手動修改日期，但新增時預設為當天當下時間 |
| Q11 | 同一天可否有多筆密碼歷程？若可，排序要再用什麼次鍵？ | 時分秒不同 |
| Q12 | 密碼歷程上限是否需要限制（例如每帳號最多 50 筆）？ | 沒有限制 |
| Q13 | 密碼欄位是否允許空白字元、特殊符號、Unicode？ | 通通允許 |

## D. 查詢與排序

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q14 | 除了類別/種類，是否要支援帳號關鍵字搜尋？ | 可以支援 |
| Q15 | 預設排序欄位與方向是什麼？（例：最近更新時間 DESC） | 預設排序 類別 種類 帳號 最近更新時間 DESC |
| Q16 | 篩選條件是否需要可同時多選（多類別/多種類）？ | 需要 |
| Q17 | 切換排序時，是否保留既有篩選條件？ | 需要保留 |

## E. UI/UX 行為細節

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q18 | 眼睛按鈕行為要「逐筆切換」還是提供「全部顯示/全部隱藏」？ | 逐筆切換 |
| Q19 | 密碼明文顯示後，是否需自動在 N 秒後恢復遮罩？若要，N=? | 1分鐘時間 |
| Q20 | 備註欄位是否限制最大字數？ | 沒有限制 |
| Q21 | 新增/編輯表單要用彈窗還是同頁展開區塊？ | 彈出對話方塊 |

## F. 匯出檔案規範

| 編號 | 問題 | 你的答案 |
|---|---|---|
| Q22 | 匯出檔名規則？（例：password-manage-YYYYMMDD-HHmmss.json） | 可以 |
| Q23 | 是否要在檔案中放入 `appName`、`formatVersion`、`createdBy` 等 metadata？ | 不需要 |
| Q24 | 未來版本升級時，是否要求向下相容舊版匯出檔？ | 需要 |

## G. 非功能與驗收

| 編號 | 問題 | 你的答案 |

| Q26 | 是否需要離線 PWA 能力（安裝到桌面、離線可用）？ | 需要 |
| Q27 | 是否有指定瀏覽器最低版本需求？ | 不需要 |
